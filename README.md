# Clinic Growth System

Working repository for turning the Clinic Growth System operating plan into a validated prototype and, later, a functional product.

## Source of truth

- Original business operating plan: `docs/pdf-understanding.md`
- Idea Reality MCP validation: `docs/mcp-validation.md`
- Our interpretations and decisions: `docs/product-hub.md`
- Product workflow: `docs/workflows.md`
- Data model: `docs/data-model.md`
- V1 scope: `docs/v1-scope.md`
- Market/clinic research: `docs/research.md`

## Working rule

Keep three layers separate:

1. **Source** — what the PDF or MCP report actually says.
2. **Interpretation** — what we understand from those sources.
3. **Decision** — what we choose to build and why.

Do not silently convert assumptions into facts.
